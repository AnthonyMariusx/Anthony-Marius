# Anthony Marius Portfolio

A responsive, mobile-friendly portfolio website for Anthony Marius.

## Features

- ✅ **Fully Responsive Design** - Works perfectly on mobile, tablet, and desktop devices
- ✅ **Mobile-First Approach** - Optimized for all screen sizes
- ✅ **Clean HTML Structure** - Semantic markup for better accessibility
- ✅ **Modern CSS** - Flexible layouts with media queries
- ✅ **Fast Loading** - Lightweight and efficient code

## Project Structure

```
AnthonyMariusx - github/
├── index/
│   └── index.html          # Main HTML file
├── css/
│   └── style.css           # Responsive styles
├── pictures/               # Image assets
└── README.md               # This file
```

## How to Use

1. Open `index/index.html` in your web browser
2. The website automatically adapts to your screen size
3. Navigate using the menu at the top

## Responsive Breakpoints

- **Mobile**: 0px - 767px (vertical navigation)
- **Tablet**: 768px and up (horizontal navigation, wider content)
- **Desktop**: 1024px and up (optimized layout)

## Browser Support

Works on all modern browsers:
- Chrome
- Firefox
- Safari
- Edge

## Getting Started with GitHub

To push this project to GitHub:

1. Create a repository on [GitHub.com](https://github.com)
2. Run these commands:
   ```bash
   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
   git branch -M main
   git push -u origin main
   ```

## Customization

- Edit `index/index.html` to add your content
- Modify `css/style.css` to change colors and styling
- Add images to the `pictures/` folder
